# Dirigent Control Center — спецификация P3 (Draft 1.0, автор: ChatGPT-руководитель)

Полная спецификация принята 18.11.2026. Ключевые решения:
- Экраны: A дашборд / B граф заказа с инспектором / C исполнители-ресурсы / D логи-расходы-аудит.
- Real-time: SSE GET /api/v1/events, события с revision + cursor (Last-Event-ID), heartbeat 15-30с,
  snapshot→SSE→apply-by-revision, при потере связи — явный индикатор, не тихий показ протухшего.
- Статусы цветами + обязательная текстовая альтернатива (доступность).
- Кнопки управления только если API реально разрешает действие в текущем состоянии.
- unknown != available; unknown-расходы показываются отдельно, не как $0.
- API: версионирование /api/v1, cursor-пагинация, idempotency-key, correlation ID,
  optimistic concurrency (expected_revision), структурированные ошибки.
- Безопасность: loopback на DE-1, панель за reverse proxy/tunnel + авторизация,
  секреты не доходят до браузера, опасные операции — отдельное подтверждение владельца.
- Принцип: API/MCP/TG/Web — интерфейсы к одному Дирижёру, не конкурирующие состояния.
