# CONTROL-drill — приёмочный тест ChatGPT (ждёт сигнала владельца)

Условия: mock-адаптеры, без Codex/DeepSeek/платного; без NexusBro; после разрешения владельца.

Тесты: 1) pause→resume (новые шаги не стартуют, running дорабатывает, без дублей)
2) retry (счётчик попыток, потолок 3 запуска, нельзя перезапустить completed)
3) cancel (каскад, повторный cancel идемпотентен)
4) recovery (рестарт демона в контрольной точке, lease восстанавливается, без двойного исполнения)

Критерии: переходы по state machine; без потерь/дублей; аудит; структурированные отказы;
MCP возвращает фактическое состояние; ноль платных операций.

Возврат перед стартом: P1 done; CONTROL доступны; разрешение создавать mock-заказы;
таблица переходов; go владельца.
